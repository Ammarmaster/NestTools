## 🗂️ Tool Categories

1. **PDF & Documents (`/pdf`)**: PDF to Word (DOCX), Word (DOCX) to PDF, Merge PDFs, Split PDFs, Compress PDFs.
2. **Unit Converters (`/converter`)**: 350+ pairwise unit conversions across Length, Mass/Weight, Area, Volume, Time, Data Storage, Speed, Pressure, and Energy.
3. **Career & Salary (`/career`)**: In-hand CTC salary calculators, wage conversion ($12/hr to $200/hr to annual salary), overtime estimators.
4. **Developer Utilities (`/developer`)**: JSON formatter & validator, SHA-256, SHA-512, MD5 hashes, Base64 encoder/decoder, URL percent encoding, UUID v4 generator, ROT13 cipher.
5. **Academic & Student (`/student`)**: CGPA calculator, 4.0/5.0/10.0 GPA scales, percentage converter, test score curve calculator, citation generators.
6. **Financial Engines (`/finance`)**: Loan EMI calculator, GST/VAT calculator, sales tax rates, discount savings calculator, mortgage estimators.
7. **Mathematics & Geometry (`/math`)**: Circle, triangle, cylinder volume, pyramid, cone, sphere, rhombus, and Pythagorean theorem solvers.
8. **Text & Content (`/text`)**: Word counter, case converters (camelCase, snake_case, Title Case), slugifier, lorem ipsum generator.
9. **Date & Time (`/date`)**: Live ticking holiday countdowns (Christmas, New Year's Eve, Thanksgiving, Halloween), age calculator, business days calculator.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ or 20+
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Ammarmaster/NestTools.git

# Navigate into the project
cd NestTools

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Next.js development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
# Compile and statically pre-render all 1,043 routes
npm run build

# Start production server
npm run start
```
